## 반복되는 설명과 최근 작업은 다른 문제다

매번 같은 보고서 형식과 숫자 표기 규칙을 설명한다면 커스텀 지침(custom instructions)을 검토할
시점이다. 반대로 조금 전 보던 제안서나 어제 정리한 회의 작업을 다시 찾기 어렵다면 필요한 것은
최근 활동을 찾는 방법이다. 둘을 한 설정으로 취급하면 꼭 지켜야 할 규칙을 우연한 기억에 맡기거나,
지나치게 많은 정보를 수집하게 된다.

기능은 플랜·플랫폼·지역·롤아웃·워크스페이스 설정에 따라 달라진다. 특히 Computer History는
ChatGPT 데스크톱 앱의 macOS 지원 환경에서만 설명하는 기능이다.

| 둘 곳 | 적합한 정보 | 피해야 할 정보 |
|---|---|---|
| 커스텀 지침 | 기본 응답 형식, 말투, 출처 표기 선호 | 특정 업무의 세부 규칙 |
| 메모리 | 오래 유지되는 선호와 되풀이되는 맥락 | 비밀값, 반드시 지켜야 할 통제 |
| 프로젝트 지침 | 해당 프로젝트의 용어, 산출물 기준, 검토 순서 | 개인의 모든 대화에 적용할 말투 |
| 프롬프트 | 이번 결과물, 자료, 제약, 완료 조건 | 다음 작업에도 그대로 쓸 일반 규칙 |

필수 규칙은 프로젝트 문서나 검토 가능한 지침에 둔다. 메모리는 유용한 맥락이지만 매번 같은
방식으로 적용된다는 보장이 있는 정책 엔진이 아니다.

## Computer History가 바꾼 점

Computer History는 이전 Chronicle 연구 미리보기를 대체했다. 단순한 이름 변경이 아니라 허용한
앱과 웹사이트에서 생기는 상호작용 이벤트를 바탕으로 최근 작업의 요약과 시간선을 만드는 별도
시스템이다. 클릭, 입력, 단축키, 앱 전환, macOS 손쉬운 사용 기능으로 얻을 수 있는 텍스트와
맥락이 요약에 쓰일 수 있다.

화면 캡처와 오디오는 기록에 포함하지 않는다. 시크릿·프라이빗 브라우징 활동도 포함하지 않는다.
다만 이벤트와 텍스트는 민감할 수 있으므로, 스크린샷을 저장하지 않는다는 사실을 민감한 정보가
수집되지 않는다는 뜻으로 오해하면 안 된다.

```text
마지막 휴식 전에 내가 하던 작업과 다음 단계는 무엇이었는지 정리해 주세요.
모호한 항목은 추측하지 말고, 원래 문서나 대화를 열어 확인해야 한다고 표시해 주세요.
```

```text
오늘 작업한 항목을 상태별로 정리해 주세요.
개인정보나 외부에 공유하면 안 되는 내용은 결과에 포함하지 말고,
확인이 필요한 항목은 별도 목록으로 남겨 주세요.
```

시간선은 원래 자료를 찾기 위한 단서다. 제안서, 대화, 파일이 실제 판단의 근거라면 해당 원본을
다시 열어 읽고 검토해야 한다.

## 켜기 전에 확인할 네 가지 권한

Computer History는 기본적으로 꺼져 있다. ChatGPT Pro 사용자는 직접 켤 수 있고, Business와
Enterprise 워크스페이스에서는 관리자가 먼저 접근을 허용해야 구성원이 각자 선택할 수 있다.
관리자 허용은 개인의 동의를 대신하지 않는다. 메모리(Memories)도 필요하며 API 키나 Amazon
Bedrock 사용에서는 제공되지 않는다.

| 경계 | 확인할 내용 |
|---|---|
| 워크스페이스 | 조직 역할에 Computer History 접근 권한이 있는가 |
| 개인 선택 | 본인이 기능을 켜려는지, 어떤 작업에 쓸지 결정했는가 |
| 메모리 | Memories가 켜져 있고 대화별 `/memories` 제어를 이해하는가 |
| 앱·웹사이트 | 포함할 앱과 URL을 허용 목록 또는 제외 목록으로 좁혔는가 |

macOS 데스크톱 앱의 **Settings > Integrations > Computer history**에서 **Turn on**을 선택하고,
권한과 로컬 저장 안내를 읽는다. 이어서 포함할 앱과 웹사이트를 고른다. Screen Recording 권한은
필요하지 않다. 설정이 보이지 않으면 플랜·지역·관리자 설정을 먼저 확인한다.

<ConceptCard title="통신·건강·재무 정보를 다룰 때">
다른 사람과의 통신을 포함할 수 있으므로, 명시적 동의 없이 대화 기록에 쓰지 않는다. 건강, 재무,
인사처럼 민감한 정보를 다루는 앱은 제외하거나 작업 전에 수집을 일시정지한다.

## 기록을 통제하고 지우는 법

macOS 메뉴 막대의 ChatGPT 아이콘과 **Settings > Computer history > History**에서 수집 상태와
기록을 확인한다. **Pause**는 새 이벤트 수집을 멈추고 **Resume**은 다시 시작한다. 앱 또는
웹사이트별 권한을 바꾸면 앞으로의 기록에는 반영되지만, 이미 만들어진 항목은 남을 수 있다.

시간선에서는 항목별 요약, 기여한 앱, 반복 작업에 대한 스킬 또는 자동화 제안을 검토할 수 있다.
항목 하나를 지우거나 최근 10분·1시간·하루·전체 기록을 지울 수 있다. 삭제는 관련 이벤트와
생성된 메모리를 함께 제거하며 되돌릴 수 없다.

임시 이벤트 파일은 Mac의 ChatGPT App Group에 격리되어 최대 48시간 보관된 뒤 삭제된다.
생성된 메모리는 `$CODEX_HOME/memories/extensions/skysight/` 아래의 일반 텍스트 Markdown 파일로
남는다. 이 파일은 Computer History가 암호화하지 않으며 같은 macOS 사용자로 실행되는 다른
프로그램이 접근할 수 있을 수 있다. Mac 계정을 보호하고, 포함하지 말아야 할 출처는 처음부터
제외한다.

수집을 일시정지해도 이전 이벤트를 요약하던 작업은 끝날 때까지 이어질 수 있다. 수집 중단과
이미 생성된 기록 삭제는 별개다. Computer History는 활동을 요약하고 메모리를 만들 때 토큰을 쓴다.
임시 이벤트 파일은 메모리를 만들기 위해 OpenAI 서버에서 처리되며, 법적 의무가 없으면 처리 후
보관하거나 학습에 쓰지 않는다. 다만 나중에 메모리가 대화 맥락으로 사용되면 그 내용은 해당
대화의 데이터 제어를 따른다. 로컬 저장이라는 표현을 모든 처리가 기기 안에서 끝난다는 뜻으로
해석하지 않는다. 지원 지역에는 EEA·영국·스위스도 포함된다.

## 실무 점검표

- 항상 지켜야 할 기준은 메모리가 아니라 프로젝트 지침과 검토 절차에 둔다.
- 켜기 전에 앱·웹사이트 허용 범위를 필요한 최소 범위로 정한다.
- 다른 사람의 통신, 건강·재무·인사 정보는 제외하거나 수집을 멈춘다.
- 시간선은 원본을 찾는 단서로 쓰고, 결과물의 근거는 원문에서 재확인한다.
- 공유·장비 교체 전에는 History에서 항목과 로컬 메모리를 검토하고 필요한 기록을 삭제한다.

개인화가 나의 기본 작업 방식을 정한다면, 다음 챕터의 프로젝트는 특정 업무의 파일·대화·지침을
한곳에 묶어 관리한다.
